Рисунок 2 - Индивидуальное задание для среднего уровня

```
// Средний уровень
#include <iostream>
#include <string>
#include <vector>
using namespace std;

class Athlete {
private:
string name;
string sport;
double record;

static int count;

public:
Athlete(string n, string s, double r) : name(n), sport(s), record(r) {
count++;
cout << "Создан спортсмен: " << name << endl;
}

~Athlete() {
count--;
cout << "Удалён спортсмен: " << name << endl;
}

void print() const {
cout << "Имя: " << name
<< ", вид спорта: " << sport
<< ", рекорд: " << record << endl;
}

static int getCount() {
return count;
}
};

int Athlete::count = 0;

class Roster {
private:
string name;
vector<Athlete*> athletes;

public:
Roster(string n) : name(n) {
cout << "Создан список: " << name << endl;
}

~Roster() {
cout << "Удалён список: " << name << endl;
}

void addAthlete(Athlete* athlete) {
athletes.push_back(athlete);
}

void print() const {
cout << "Список спортсменов " << name << ":" << endl;

for (const auto& athlete : athletes) {
athlete->print();
}
}
};

int main() {
setlocale(LC_ALL, "ru");

Athlete a1("one", "Бег", 10.5);
Athlete a2("two", "Плавание", 52.3);

cout << "\nКоличество спортсменов: "
<< Athlete::getCount() << endl;

{
Roster roster("Russia");
roster.addAthlete(&a1);
roster.addAthlete(&a2);

roster.print();
}

cout << "\nСписок уничтожен, но спортсмены существуют:" << endl;

a1.print();
a2.print();

cout << "Количество спортсменов: "
<< Athlete::getCount() << endl;

return 0;
}
```

**Контрольные вопросы:**
1. Что такое композиция? Приведите пример.
Композиция — это отношение между классами, при котором один объект содержит другой объект как свою часть. Например, класс Car содержит объект Engine.
2. Что такое агрегация? Чем она отличается от композиции?
Агрегация — это отношение, при котором один объект использует другой, но тот может существовать отдельно. При композиции часть тесно связана с целым, а при агрегации может существовать независимо.
3. Как реализовать композицию в C++? Приведите пример кода.
Композиция реализуется через поле класса, которое является объектом другого класса.
class Engine {
public:
    void start() {}
};

class Car {
private:
    Engine engine;
};
Объект Engine является частью объекта Car.

4. Как реализовать агрегацию в C++? Приведите пример кода.
Агрегацию можно реализовать с помощью указателя или ссылки на объект другого класса.
class Engine {
public:
    void start() {}
};

class Car {
private:
    Engine* engine;

public:
    Car(Engine* e) {
        engine = e;
    }
};
Объект Engine создаётся отдельно и может существовать независимо от Car.

5. В чём разница между временем жизни частей при композиции и агрегации?
При композиции время жизни части обычно связано с временем жизни целого. При агрегации часть может существовать до создания целого и после его уничтожения.

6. Что такое статическое поле класса? Чем оно отличается от обычного поля?
Статическое поле принадлежит всему классу и является общим для всех его объектов. Обычное поле принадлежит каждому объекту отдельно.

7. Как объявить и определить статическое поле? Где оно хранится?
Статическое поле объявляется с помощью ключевого слова static, а вне класса обычно определяется отдельно.
class Test {
public:
    static int count;
};

int Test::count = 0;
Оно хранится в статической области памяти программы, а не внутри каждого отдельного объекта.

8. Что такое статический метод? Можно ли из него обратиться к нестатическим полям?
Статический метод принадлежит классу и вызывается без создания объекта. Напрямую обращаться к нестатическим полям из него нельзя, поскольку у него нет указателя this.

9. Для чего используются статические счётчики объектов?
Они используются для подсчёта количества созданных объектов класса или отслеживания текущего количества существующих объектов.

10. Что такое паттерн «Одиночка» (Singleton)? Для чего он нужен?
Singleton — это паттерн проектирования, который обеспечивает существование только одного экземпляра класса и предоставляет общий способ доступа к нему.

11. Как запретить создание копий объекта (конструктор копирования)?
Нужно объявить конструктор копирования в закрытой секции private или удалить его с помощью = delete.
class Test {
public:
    Test(const Test&) = delete;
};

12. В каком порядке вызываются конструкторы и деструкторы при композиции?
Сначала вызываются конструкторы частей, затем конструктор целого. При уничтожении сначала вызывается деструктор целого, затем деструкторы его частей. Порядок создания частей определяется порядком их объявления в классе.

13. Можно ли изменить статическое поле из обычного метода?
Да. Обычный метод может изменять статическое поле, поскольку оно доступно всем объектам класса.

14. Почему статические поля нужно определять вне класса?
В обычном случае статическое поле отдельно определяют вне класса, чтобы выделить для него память и задать начальное значение. В C++17 и новее можно использовать inline static и определить поле непосредственно внутри класса.

15. В каких случаях стоит использовать композицию, а в каких — агрегацию?
Композицию используют, когда объект является неотъемлемой частью другого объекта. Агрегацию используют, когда объекты связаны между собой, но могут существовать независимо друг от друга.

# Домашняя работа - лаба 1

## Описание проекта

Программа на C++, демонстрирующая работу с классами, статическими полями и методами, конструкторами и деструкторами, а также использование `vector` для хранения указателей на объекты.

Программа позволяет создавать спортсменов, объединять их в список, выводить информацию о них и отслеживать количество существующих объектов класса `Athlete`.

## Функциональность

- Создание объектов спортсменов с именем, видом спорта и рекордом.
- Подсчёт количества созданных и существующих спортсменов.
- Добавление указателей на спортсменов в список `Roster`.
- Вывод информации о спортсменах.
- Демонстрация работы деструктора при уничтожении списка.
- Демонстрация того, что удаление списка не приводит к удалению самих спортсменов.

## Структура программы

### Класс `Athlete`

Представляет спортсмена.

**Поля:**
- `name` — имя спортсмена.
- `sport` — вид спорта.
- `record` — спортивный рекорд.
- `count` — статическое поле, хранящее количество существующих объектов `Athlete`.

**Методы:**
- `Athlete()` — конструктор, инициализирующий поля объекта, увеличивающий счётчик и выводящий сообщение о создании спортсмена.
- `~Athlete()` — деструктор, уменьшающий счётчик и выводящий сообщение об удалении спортсмена.
- `print()` — выводит информацию о спортсмене.
- `getCount()` — статический метод, возвращающий количество существующих спортсменов.

### Класс `Roster`

Представляет список спортсменов.

**Поля:**
- `name` — название списка.
- `athletes` — вектор указателей на объекты класса `Athlete`.

**Методы:**
- `Roster()` — конструктор, задающий название списка.
- `~Roster()` — деструктор, выводящий сообщение об удалении списка.
- `addAthlete()` — добавляет указатель на спортсмена в вектор.
- `print()` — выводит название списка и информацию обо всех спортсменах в нём.

## Используемые технологии

- **C++** — язык программирования.
- `<iostream>` — ввод и вывод данных.
- `<string>` — работа со строками.
- `<vector>` — хранение динамического массива указателей.

## Принцип работы

1. Создаются два спортсмена: `one` (бег, рекорд 10.5) и `two` (плавание, рекорд 52.3).
2. Выводится количество существующих спортсменов — `2`.
3. Внутри отдельного блока создаётся список `Russia`.
4. В список добавляются указатели на обоих спортсменов.
5. Выводится информация о спортсменах.
6. При завершении блока объект `Roster` уничтожается, вызывается его деструктор.
7. Спортсмены продолжают существовать, поскольку они были созданы вне блока и список хранит только указатели на них.
8. Повторно выводится информация о спортсменах и их количество.

## Компиляция и запуск

Для компиляции с помощью компилятора g++ выполните команду:

```bash
g++ main.cpp -o main
```

Для запуска в Linux:

```bash

```

## Вывод

Программа демонстрирует связь между двумя классами: `Roster` хранит указатели на объекты `Athlete`, но не управляет временем их жизни. Уничтожение списка не удаляет спортсменов, поэтому их данные остаются доступными до завершения области видимости соответствующих объектов.
